# faulty
Digital Musician studying online computing.

This repo is my personal website: plain HTML, CSS, and JavaScript, with no build step.

## Run it locally

Open `index.html` in a browser, or serve the folder:

```sh
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Publish with GitHub Pages

1. On GitHub, go to **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Pick the `master` branch and the `/ (root)` folder, then save.
4. The site goes live at `https://faultymushr00ms.github.io/faulty/` after a minute or so.

## Making it yours

Search `index.html` for `TODO` and fill in each one:

- Release titles, artwork, and links (or swap in SoundCloud/Bandcamp/Spotify embeds)
- Streaming and social profile URLs
- The About text and the list of tools and skills
- Real projects
- A contact email you're happy to have public

Colours and fonts are set as variables at the top of `styles.css`.
